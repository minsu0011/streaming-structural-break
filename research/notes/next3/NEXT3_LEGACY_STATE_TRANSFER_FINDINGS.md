# NEXT3 legacy 상태 세분화 결과

기존 O1 합성 사례에서 legacy 상태의 후기 반응은 주로 EWMA 상태 개입에 의해 달라졌습니다. 앵커 127/255의 [256,512) 창에서 대조군 EWMA를 이상치 상태에 넣으면 평균 확률이 약 0.114823 감소하고, 반대 방향에서는 약 0.115508 증가했습니다. 원본 미래 관측은 동일하며 개입은 평가용입니다.

앵커 0의 AR 필터·lag ring 교환 효과가 후기 창에도 남지만 앵커 127부터는 두 상태의 교환 효과가 0입니다. 반면 EWMA 효과는 유지됩니다. 필터의 초기 차이가 누적 상태로 전달되는 해석과 부합합니다. EWMA 안의 개별 셀이나 시간척도를 추가 탐색하지 않았으므로 160 척도 하나만 고유 원인이라고 단정하지 않습니다.

양/음 CUSUM의 0 효과는 메모리 문제가 해결되었다는 증거가 아닙니다. 동결된 tree-used 모델이 legacy 열 3/4를 사용하지 않아 해당 CUSUM 상태가 활성 입력에 포함되지 않습니다. Running mean 열 5는 사용되지만 후기 영향은 훨씬 작습니다.

모든 원본 J102/C205/BL80 예측 3,145,728개, 복제 재생 3,756회, 7개 상태 전체와 기존 legacy 전체 교환의 비교 3,756회가 정확히 일치했습니다. D005의 legacy 평균 궤적 2,814개와 90개 창 결과도 정확히 재구성했습니다. 630개 새 세부 창/지표와 9,476,096개 평가용 hybrid 예측을 계산했으며 신규 fit·후보·DEV 관측 접근·seal 접근은 0입니다.
