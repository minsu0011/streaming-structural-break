# Future independent validation, without consuming it in NEXT3

No seal opening, new reduced evaluation or public/cloud submission is authorized
by this run. All four sealed partitions remain untouched. This document is a
future decision plan, not a queued external action.

The finite NEXT3 scientific menu does not justify spending a seal. No candidate
passes the fixed performance or robustness conditions. Prediction-exact runtime
engineering can be tested against the frozen models on every already available
observation without obtaining new labels. If accepted after final reproduction,
that would improve deployment cost while preserving the existing scientific
claim and its existing generalization limitations.

A future scientific candidate should first be frozen as one complete recipe:
features, H-only calibration, tree parameters, weights/gate, split policy, code,
canonical model bytes, prediction interface, score aggregation and a single
decision rule. A small effect discovered after many DEV trials is not made
independent by changing CV seeds or by selecting a favorable mechanism slice.
The original and alternate partitions are useful stability evidence but all use
the same repeatedly inspected DEV observations.

Before any separately authorized independent evaluation, record which single
candidate and which single frozen reference will be compared, the one primary
metric (official TS-AUC), required paired-series uncertainty, and exact handling
of ties, undefined time strata and missing diagnostics. Fix the interpretation of
small or negative results in advance. Keep all candidates that failed earlier
gates in the ledger; do not reopen a large menu after seeing the independent result.

Mechanism diagnostics need support independently of an overall score. Current
DEV has only 132 SCALE_DOMINANT break series and 79/53 observed-window decreases/
increases. A 500-series seal is not guaranteed to contain 100 scale breaks, or to
represent the same mechanism proportions as DEV. No actual sealed proportions
are known or estimated from sealed metadata here. A narrow DEV conditional CI
does not imply that such a seal will precisely validate a scale-specific effect.

If an independent result later fails its frozen decision rule, retain the result
and stop the claimed promotion. Do not use that partition to revise the recipe
and describe another score on it as independent confirmation. Prefer additional
genuinely new data or a predeclared external evaluation for the next claim.

The current max-standardized bootstrap envelope describes only the twelve fixed
full-CV predictions available at its start. It excludes uncertainty from fitting,
screening, choosing hypothesis families, earlier sessions and distribution shift.
It is not an unconditional family-wise or selective-coverage guarantee. These
limitations remain even if a particular lower bound is positive.

For the next research session, the three priorities are: obtain stronger
independent evidence before a scientific claim; explain and repair the real-DEV
scale/dependence tradeoff with a genuinely new mechanism; and preserve the exact,
reproducible deployment path. Repeating 0.01 weight grids, changing random seeds
or retesting the same negative variants is not part of this plan.
