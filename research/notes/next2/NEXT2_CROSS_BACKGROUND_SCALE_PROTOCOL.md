# 고정 분산 변화의 배경별 보조 진단

원래 counterexample lock에는 Gaussian / AR / ARCH / heavy-tail 네 배경이 열거되어 있지만, 주 18개 시나리오의 V1–V4는 ARCH 배경 한 종류다. 주 suite와 기존 결과는 변경하지 않는다. 분산 감소 약점이 ARCH에 한정되는지 확인하기 위해, 그 네 배경과 기존 분산 배수 1.5 / 2 / 0.7 / 0.5의 전체 4×4 조합을 한 번의 보조 진단으로 고정한다.

배경의 phi/alpha/Student-t 자유도는 주 suite의 N0/N1/N2/N3 값 그대로다. H=2048, burn-in=1024, O=1024, 예정 변경 128/256/512, 512 seed도 같다. 기존 생성 함수는 수정하지 않고 별도 RNG partition=3을 사용한다. 배경 안에서는 네 분산 배수가 같은 H·변경 전 관측·잠재 잡음을 공유한다. 따라서 같은 배경의 control은 한 번만 생성한다. calibration은 원래 partition=0의 동일 배경 무변화 표본을 재사용한다.

동결 all-DEV J102/Y001/B104/C205와 기존 J102/C205 80/20만 검사한다. 새 fitting, 모델 선택, 가중치 선택은 없으며 원래 suite 결과를 이 결과로 대체하지 않는다. 효과 크기와 방향, strict-threshold 경보, 변경 후 검출을 모두 보고한다. 합성 반례에 대한 모델 개선 학습은 하지 않는다. 별도 보조 진단이며 competition 일반화나 승격의 근거로 사용하지 않는다.
