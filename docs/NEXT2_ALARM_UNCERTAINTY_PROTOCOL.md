# Calibration and evaluation uncertainty for the fixed late-alarm diagnostic

This supplemental analysis is registered after the four long-late cohorts and their point estimates were inspected. It estimates uncertainty around those existing findings; it is not prospective confirmation, candidate selection, or a new promotion gate. All models, transformations, thresholds, generators and samples remain unchanged.

Use all five frozen all-DEV models, the four cells in `LATE_ALARM_DIAGNOSTIC_LOCK.json`, beta 0, 0.5 and 1, and alpha 0.01 and 0.05. Calibration consists of 1,000 independently generated 1,024-point null trajectories in the matching background. Evaluation consists of 128 matched control/intervention pairs, each of length 65,536. The intervention occurs at 4,096 or 49,152 and multiplies variance by 2.

For each background, generate 2,000 bootstrap calibration index vectors with NumPy PCG64 seed `2026090953 + background ordinal` (N0 = 0, N2 = 1), using the unchanged finite-sample order-statistic threshold. Use identical calibration indices across models, beta values, alpha values and onset cells within that background. Independently generate 2,000 evaluation pair index vectors using seed `2026090957 + cell ordinal`; resample a control and its intervention together and use identical draws across models and transformations. Calibration and evaluation samples never mix.

Measure control eventual alarm rate, intervention premature alarm rate, and intervention clean post-change first-detection rate, including detection within 10, 50 and 128 points. A clean detection requires no pre-change threshold crossing. Pre-change and post-change maxima are sufficient for these events; verify every point estimate against the existing complete-trajectory first-alarm implementation.

Report percentile intervals for each statistic and paired differences against raw J102, as well as within-model differences against beta 0. Retain the complete bootstrap vectors. These are empirical bootstrap sensitivity intervals conditional on the already fitted models, fixed synthetic generators and observed samples. They include calibration-sample variability but do not provide selection-adjusted coverage, an anytime guarantee, model-fitting uncertainty, or competition performance evidence. A bootstrap interval collapsing to zero when all sampled trajectories have zero detections is not evidence that the population detection probability is exactly zero. Do not select an exponent or threshold from these results.
