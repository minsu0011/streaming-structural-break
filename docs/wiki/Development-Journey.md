# 통계 기준선에서 NEXT2로

## 순차 처리 기준선

문제의 입력은 과거 H와 앞으로 하나씩 전달되는 O입니다. 전체 O를 보고 정규화하거나 길이를 미리 사용하는 순간 순차 탐지 문제가 달라집니다. 처음에는 평균·분산 등 직접 해석할 수 있는 streaming 통계를 기준으로 삼았습니다.

## AR4/AR8: 배경 의존성과 변화 분리

자기상관이 강한 시계열에서는 원시 관측의 연속 움직임이 정상 배경일 수 있습니다. AR4/AR8은 이 배경을 설명한 잔차를 만들어 입력 표현을 넓힙니다. ARCH 경로는 변동성 상태를 별도로 다룹니다.

차수와 정규화 방식은 모델 후보의 일부입니다. 더 긴 history나 높은 차수를 도입했다고 자동으로 더 좋은 변화 신호가 되는 것은 아닙니다. 같은 분할의 성과와 부담을 함께 확인해야 합니다.

## NEXT의 누적 증거

원시 에너지와 분산 관련 채널에서 순간값, EWMA, CUSUM, GLR와 Bayes 요약을 만들었습니다. 짧은 변화와 오래 이어지는 변화를 함께 표현하려는 선택입니다.

문제는 정상 상태의 예측 채널도 serial correlation을 가질 수 있다는 점입니다. 독립 관측을 가정한 누적 분산은 긴 age의 증거를 과장할 수 있었습니다. Serial variance 후보는 H에서 추정한 lag-1 상관으로 합의 분산을 보정했습니다.

이 변경은 모든 특징을 대체하지 않습니다. 순간값·EWMA·CUSUM과 과거 AR/ARCH fitting을 유지하고, 누적 GLR·Bayes 및 관련 memory 경로를 구분해 바꿨습니다.

## NEXT2: primary의 반례를 보완

분산 primary가 강하더라도 의존성만 달라지는 경우를 놓칠 수 있습니다. NEXT2에서는 dependence, scale, sign 등의 보완 입력을 따로 만들고 어떤 반례에서 추가 정보가 생기는지 살폈습니다.

저장된 performance 설정은 J102 serial-variance primary와 C205 dependence complement의 고정 blend입니다. 이름이 새로운 세대라고 모든 부분을 새로 학습하는 구조는 아닙니다. 강한 기존 성분을 유지하고 별도 메커니즘을 보완하는 방식입니다.

## 후보를 줄이는 기준

모델 평균만 올리는 후보, 최악 fold를 해치는 후보, 다른 배경에서 효과가 사라지는 후보를 구분합니다. Simplification과 performance 역할의 gate도 별도로 둡니다. 단순화는 계산 부담을 줄이면서 성과를 유지하는 질문이고, 성능형은 추가 이득을 요구하는 질문입니다.

실행에서는 여러 모델이 공유하는 상태와 실제 사용하는 특징을 재사용합니다. 이 최적화는 점수 변경 없이 같은 계산을 제공해야 하므로 수치 일치와 입력 소비 순서를 별도로 확인하도록 설계했습니다.
