# 분산 신호와 의존성 신호

통계 기준선에서 AR4/AR8 잔차로 배경 자기상관과 새로운 변화를 분리했습니다. NEXT에서는 누적 분산 증거가 과장되는 문제를 과거 구간의 serial variance로 보정했습니다.

NEXT2는 분산 primary를 유지하고 의존성 변화의 보완 모델을 결합합니다. 추가 모델이 독립적인 신호를 주는지, 최악 구간과 실행 비용을 악화시키지 않는지 함께 봅니다.

세대별 분할·평가 조건이 달라 통합 개선율을 제시하지 않습니다. [개발 과정](wiki/Development-Journey.md)과 [계산 구조](wiki/Model-Evolution.md)에 선택 근거를 정리했습니다.
