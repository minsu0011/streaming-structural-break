이 문서는 첫 폴드 합성 스트레스 결과를 읽은 연구 중간 기록이다. 전체 폴드 결과나 최종 모델 선택을 대신하지 않는다. 원본 근거는 `artifacts/next5/synthetic/candidates/<candidate>/full/fold_0/ANALYSIS/`의 CSV와 해시 영수증이다.

## X2는 ResearchPool에서 가장 높지만 범용 scale 개선은 입증하지 못했다

X2_SCALE_TAIL의 ResearchPool 5-fold 평균은 0.6215608600890692이고, 동일 학습 범위의 BL80 대비 증가분은 0.0011956500192103591이다. 고정 승격 기준 0.0012와의 차이는 -0.000004349980789640755다. 표시 자릿수를 줄여 이 차이를 없애지 않는다.

첫 폴드 합성 검증에서는 V1/V2 분산 증가에서 각각 +0.00777724/+0.00232672였지만, V3/V4 분산 감소에서는 -0.01836674/-0.01506606이었다. 두 감소 조건의 기존 2000개 seed bootstrap 구간도 모두 0보다 낮았다. 다른 N3 배경의 감소 조건에서는 0.7배가 -0.00505865, 0.5배가 +0.00307467로 엇갈렸다. 따라서 감소 폭만으로 일반화 방향을 단순하게 설명할 수 없다.

T2 heavy-tail 조건에서는 +0.02167940이었다. 하지만 이 이득이 감소 조건의 손실을 없애는 것은 아니다. 실제 데이터 SCALE slice의 좋은 결과 역시 모든 생성 분포의 scale 변화에 강하다는 보장은 아니다.

X2의 첫 폴드에서 O1/OB16의 평균 paired probability excess는 BL80보다 각각 0.00757238/0.00367404 낮았다. 이 수치만으로 충격 회복이나 검출 성능 개선을 선언하지 않는다. 고정 0.9 BL80 + 0.1 expert 조합의 점수 진폭 감소 효과가 포함될 수 있다. 기존 임계값 보정 후 오경보, 진짜 변화 검출, 학습 폴드 간 차이를 함께 확인해야 한다.

고정 1024 길이 calibration에서 alpha=0.05로 정한 임계값을 16384까지 유지했을 때, X2 첫 폴드의 eventual false alarm은 N0 0.33203125, N1 0.3984375, N2 0.4609375, N3 0.41796875였다. 대응 BL80은 0.3203125, 0.40234375, 0.4609375, 0.4140625다. 장기 오경보를 일관되게 줄이지 않았다. 여기서 alpha=0.05는 16384 horizon의 보장이 아니다.

## 원인 분석을 위해 추가한 진단의 한계

`scale_direction_response/POLICY_LOCK.json`은 위 실패를 본 뒤 등록한 사후 진단이다. 기존 6개 scale 생성 조건, 256개 seed, 1024 horizon, 고정된 S4B 80개와 R2 16개 특성을 그대로 사용한다. 추가 모델 학습과 새로운 예측 실행 없이 이미 저장된 7개 후보 × 5개 폴드 점수의 변화 반응을 비교한다.

진단 onset은 생성기의 알려진 변화 시점을 기준으로 결과를 정렬하는 용도로만 쓰며, feature state에는 전달하지 않는다. lag 512는 onset 512에서 관측 범위를 벗어나므로 새 길이로 생성하지 않는다. 관측 가능한 171개 seed의 지원 수를 명시한다. seed별 age 구간 평균을 먼저 계산하므로 긴 시계열이 자동으로 큰 가중치를 얻지 않는다.

이는 실패의 설명을 돕는 기술 통계다. 독립 검증, 특성 ablation, 학습된 제품항의 인과 효과, 새 promotion gate는 아니다.

## 실행 및 전달 준비

실제 learner fit 295개는 fit 시작·완료 영수증, 모델 바이트, 학습 ID, held-out 분리, 사전 등록 해시와 일치했다. 이후 실행 그래프 중간 감사에서는 등록 작업 400개와 고정 Python 소스 57개를 검증했다. 이 스냅샷에는 완료 181개, 실행 중 1개, 대기 214개, 보존된 quarantine 4개가 있었으며 대기 작업을 완료로 계산하지 않았다.

GPT 전달용 목록은 raw competition data, real point OOF, 특성 캐시, 기존 압축파일을 제외한다. 최초 목록 필터가 이전 portable 검증 영수증까지 거부한 오류는 파일 생성 전 발견돼 수정됐고, `maintenance/PAYLOAD_PREVIEW_FILTER_RECOVERY.json`에 남겼다. 현재 검토 목록은 최종 ZIP이 아니며, 연구 10시간과 별도 감사 50분 이후에만 최종 전달물을 생성한다.

`worst_delta`는 후보의 최저 fold 점수에서 BL80의 최저 fold 점수를 뺀 값이다. `minimum_fold_delta`는 같은 fold끼리 뺀 차이들 중 최솟값이다. 특히 S4A는 전자가 +0.00005228이어도 후자는 -0.00123838이다. 원래 고정된 수치 판정은 보존하고, 두 값과 더 엄격한 matched-fold 기준의 통과 여부를 모두 표시한다. 모든 full 후보가 평균 증가분 기준에 미달하므로 이 구분으로 최종 자격이나 Shadow 정책이 바뀌지 않는다.
