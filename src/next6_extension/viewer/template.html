관측 상태전이망

화살표나 상태 원을 선택하면 확률의 오차 범위와 지원 자료를 볼 수 있습니다.

화살표는 상태를 떠날 때의 비중입니다. 화살표와 원을 클릭하거나 Tab으로 선택할 수 있습니다. 아래 두 확률은 방금 관측한 같은 전이를 두 조건에서 함께 계산합니다. 조건 선택은 그림만 바꾸며 현재 상태 계산을 바꾸지 않습니다.

현재 완성 구간의 노드 상태

점선은 H 상대값 ±2입니다. 모든 노드는 같은 원자료를 공유합니다. 서로 다른 노드 수를 독립된 원인의 수로 해석하지 않습니다.

그림과 검증 범위

상태전이 화살표는 fold 0 학습 5,120개 series의 실제 관측 빈도입니다. 상태를 떠나는 전이 중 지원 series 8개 이상·비중 3% 이상만 표시합니다. 모든 조건부 확률은 설명용이며 경제적 인과관계를 뜻하지 않습니다. 표시한 오차 범위는 학습 series를 통째로 500회 재표집한 95% 구간입니다. 7개 상태 이름만으로 다음 상태가 결정되는 것은 아닙니다. 실제 계산은 최근 네 구간, 구간 내 시점, 충격 대기와 회복 횟수를 함께 기억합니다. 화살표는 이런 상황을 합친 평균 빈도입니다.

합성 사례는 결과 확인 전에 고정한 seed 0입니다. 실제 RP 사례는 미리 정한 해시 순서에서 선택했습니다. 원자료는 이 HTML에 포함하지 않았고, 상태와 점수만 포함했습니다. 이 화면은 외부 서버 연결 없이 실행됩니다.
