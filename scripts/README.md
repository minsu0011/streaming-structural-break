# 실험 도구

학습, 평가, 합성 반례 분석, runtime 측정을 위한 스크립트입니다.

- 기본 연구 경로: `run_research.py`, `run_real_research.py`
- 후속 연구: `next7/`, `next8/`, `next9/`
- 모델별 외부 진입점: `../entrypoints/`

파일명의 단계·버전 표기는 당시 실험 구현을 구분합니다. 이 디렉터리는 독립 실행 가능한 예제 모음이 아닙니다. 일부 도구는 원본 데이터와 해당 시점의 `artifacts/`를 필요로 합니다. 실험 결과 표는 `../research/reports/`에 있습니다.
